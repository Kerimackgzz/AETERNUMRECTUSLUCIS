5. BRANCH VE WORKTREE KURULUMU

Repository kökünde:

git checkout main
git pull
git switch -c integration
git push -u origin integration

Foundation:

git worktree add -b agent/codex-architecture-security ../aeternum-codex-architecture integration

Foundation merge’inden sonra:

git worktree add -b agent/claude-design-pages ../aeternum-claude-design integration
git worktree add -b agent/claude-home-hero ../aeternum-claude-hero integration
git worktree add -b agent/codex-commerce ../aeternum-codex-commerce integration

Branch mevcutsa `-b` kullanma; mevcut branch’i worktree’ye bağla.

6. KORUNAN BRANCH KURALLARI

- Hiçbir ajan main’e doğrudan commit veya push yapamaz.
- Hiçbir ajan integration’a doğrudan commit veya kontrolsüz push yapamaz.
- Force push yapma.
- Her ajan yalnızca kendi branch’inde çalışır.
- Merge işlemini Coordinator yapar.
- Küçük ve anlamlı commitler oluştur.
- Her ajan merge öncesi branch’ini integration ile günceller.
- Çakışmayı mümkünse dosya sahibi çözer.

14. MIGRATION GATE

Migrations klasörü ve ModelSnapshot üzerinde aynı anda yalnızca bir ajan çalışabilir.

Sıra:

1. Ajan 3 ilk Identity migration’ını oluşturur.
2. Foundation integration’a merge edilir.
3. Migration ownership Ajan 4’e devredilir.
4. Ajan 4 branch’ini güncel integration üzerinden oluşturur.
5. Bundan sonra Ajan 4 commerce migrationlarını üretir.

Diğer ajanlar migration oluşturamaz, silemez veya yeniden adlandıramaz.
Migration conflict elle birleştirilmez; gerekirse son migration temiz branch üzerinde yeniden üretilir.
